# clipping at 1.0, which kept 2048 x 3 stable where the first grid diverged
# (stochastic-diagnosis.txt). First the two-stage comparison at 512 x 3:
# three mean models (MSE: on all the data, and on each half, in alternating
# 60-second blocks) for two-stage-2.txt, and the joint beta-NLL model they
# compare with. Then the size x length grid, largest first.
